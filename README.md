# Набор AI Skills для работы с нейронными сетями

Репозиторий содержит два навыка (Agent Skills), которые помогают ИИ-агенту выполнять типовые этапы ML-проекта:

1. **dataset-audit** — анализ и подготовка данных перед обучением.
2. **neural-network-trainer** — планирование обучения, обучение и оценка качества нейросети.

## Структура

```text
neural-network-skills/
├── README.md
├── dataset-audit/
│   └── SKILL.md
└── neural-network-trainer/
    └── SKILL.md
```

## Когда использовать

| Навык | Запускается, когда пользователь просит… | Результат |
|---|---|---|
| `dataset-audit` | проверить датасет, очистить данные, подготовить признаки, найти пропуски и дисбаланс классов | отчёт о качестве данных и воспроизводимый план предобработки |
| `neural-network-trainer` | создать, обучить, настроить или сравнить нейросеть | план эксперимента, код обучения, метрики и выводы |

## Как подключить

Скопируйте папки навыков в каталог `skills` вашего ИИ-агента или в другой каталог, который поддерживает выбранная платформа. Способ обнаружения и активации навыков зависит от агента.

Это инструкции для ИИ-агента, а не готовые веса нейросети и не автономное приложение. Агент должен иметь доступ к соответствующим файлам и, если требуется запуск кода, к Python-среде.
